# Satyabrata Das Portfolio

A modern personal portfolio website for Satyabrata Das, built to showcase software engineering, AI/ML, computer vision, iOS, hackathon, and project experience with a polished animated frontend.

The site is built with React and Vite, styled with custom CSS, and enhanced with Anime.js-powered entrance, scroll, hover, and hero animations.

## Highlights

- Responsive portfolio layout for desktop, tablet, and mobile
- Animated hero section with interactive background lighting
- Polished project cards with screenshots, metadata, tech stacks, and external links
- Sections for About, Education, Academic Presentation, Skills, Experience, Hackathons, Projects, and Contact
- Mobile navigation menu with accessible toggle behavior
- Reduced-motion support for users who prefer minimal animation
- Production build and lint scripts included
- GitHub Pages deployment support via `gh-pages`

## Tech Stack

- React 19
- Vite
- Anime.js
- Custom CSS
- ESLint
- GitHub Pages

## Getting Started

Clone the repository and install dependencies from the React app directory:

```bash
git clone https://github.com/Satyabratadas/Satyabratadas.github.io.git
cd Satyabratadas.github.io/app
npm install
```

Start the local development server:

```bash
npm run dev
```

The app will run locally with Vite. Open the URL shown in the terminal, usually:

```text
http://localhost:5173/
```

## Available Scripts

Run these commands from the `app` directory.

```bash
npm run dev
```

Starts the Vite development server.

```bash
npm run build
```

Creates a production build in `app/dist`.

```bash
npm run preview
```

Previews the production build locally.

```bash
npm run lint
```

Runs ESLint checks.

```bash
npm run deploy
```

Builds and deploys the site to GitHub Pages using `gh-pages`.

## Deployment

This repository is configured for deployment with GitHub Pages.

From the `app` directory:

```bash
npm run deploy
```

The deploy script builds the app and publishes the `dist` folder through `gh-pages`.

## Quality Checks

Before deploying, run:

```bash
npm run lint
npm run build
```

Both commands should complete successfully before publishing changes.
